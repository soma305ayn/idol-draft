# 小説メモ

小説を書くためのメモアプリ。`index.html` 1ファイルで動く（外部ライブラリなし・ビルド不要）。

## 使い方

- Chrome / Edge（PC）で `index.html` を開く。GitHub Pages なら `/novel-memo/`。
- 「フォルダを開く」で原稿フォルダを選ぶと、中の `.txt` / `.md`（3階層まで）が左に並ぶ。
- 書いた内容は約0.8秒後にそのファイルへ直接上書き保存される。`Ctrl+S` で即保存。
- 次回は「前回の〇〇を開く」で同じフォルダを開き直せる。最後に開いたファイルも復元。
- File System Access API 非対応のブラウザでは、端末内（localStorage）に一時保存し、「ダウンロード」で書き出す。

## 気になる表現

- 右の欄で表現とメモを登録。`Ctrl+Shift+K` で本文の選択中の文字を登録。
- 本文中の該当箇所に色が付き、件数が出る。「前」「次」で該当箇所へ移動、「全ファイル」でフォルダ内を横断検索。
- `Ctrl+K` で呼び出しパレット。Enter で本文に挿入、Shift+Enter で本文中を探す。未登録の文字なら Enter で登録。
- 表現リストは開いたフォルダの `.novel-memo-expressions.json` にも保存される（ブラウザにも保存）。

## その他

- Tab キーで全角スペースを入力。
- 明朝／ゴシック、文字サイズ、縦書きを切り替えられる。
