# Hybrid Memo

Obsidian と Notion の「良いとこどり」をしたメモアプリです。ビルド不要・依存ライブラリなしの静的 Web アプリで、`index.html` をブラウザで開くだけで動きます（GitHub Pages でもそのまま公開可能）。

## 機能

| 由来 | 機能 |
| --- | --- |
| Obsidian | Markdown 編集（編集 / 分割 / 閲覧モード） |
| Obsidian | `[[ウィキリンク]]`・`[[ノート\|別名]]`・`[[ノート#見出し]]`、未作成リンクはクリックで新規作成 |
| Obsidian | バックリンク・**未リンクの言及**（ワンクリックでリンク化） |
| Obsidian | `#タグ`（日本語・`#親/子` 対応）、`![[埋め込み]]`、`> [!note]` コールアウト |
| Obsidian | グラフビュー（ドラッグ・ズーム・タグ表示切替） |
| Obsidian | デイリーノート、コマンドパレット（`Ctrl/⌘+K`） |
| Obsidian | ローカルファースト（ブラウザ内保存）、`.md`（frontmatter 付き）の入出力 |
| Obsidian | タイトル変更時に他ノートのリンクを自動更新 |
| Notion | `/` スラッシュコマンド（見出し・ToDo・表・コールアウト・子ページ作成など） |
| Notion | ページの入れ子（サイドバーでドラッグして階層変更）、パンくずリスト |
| Notion | ページアイコン、お気に入り |
| Notion | 型付きプロパティ（テキスト / 数値 / 日付 / セレクト / マルチセレクト / チェック / URL） |
| Notion | データベース（表）ビュー：並べ替え・絞り込み・セル直接編集 |
| Notion | ボード（カンバン）ビュー：ドラッグでステータス変更 |

その他：ダーク / ライトテーマ、モバイル対応、リスト入力の自動継続、`Tab` でインデント、複数タブ間の同期。

## ショートカット

| キー | 操作 |
| --- | --- |
| `Ctrl/⌘ + K`（または `P`） | 検索・コマンドパレット（`>` でコマンドのみ） |
| `Alt + N` | 新規ノート |
| `Ctrl/⌘ + E` | 編集 / 閲覧の切替 |
| `Ctrl/⌘ + B` / `I` | 太字 / 斜体 |
| `/` | スラッシュコマンド |
| `[[` | リンク候補 |

## データ

- データはブラウザの `localStorage`（キー `hybrid-memo:v1`）に保存されます。
- サイドバー下部の「バックアップ」で全データを JSON 書き出し、「インポート」で JSON / `.md` を取り込めます（`.md` ファイルを画面にドロップしても可）。
- `.md` の frontmatter はプロパティに対応付けられ、未知のキーは自動でプロパティとして追加されます。

## 構成

```
memo/
├── index.html      # エントリポイント
├── style.css       # スタイル（ライト / ダーク）
├── markdown.js     # Markdown → HTML 変換、リンク・タグ抽出、frontmatter（ブラウザ / Node 両対応）
├── app.js          # アプリ本体（状態管理・各ビュー・エディタ）
└── tests/          # markdown.js のユニットテスト
```

## テスト

```sh
node --test memo/tests/*.test.js
```
